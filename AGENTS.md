# Photoshop Tool contributor guidance

- Work on `develop` unless the owner explicitly changes the branch scope. Do not merge into `main` automatically.
- Run `npm test`, `npm run build`, and `npm run check`. Python's `zipfile` can independently inspect the CCX. No npm dependencies/install step.
- `package.json` owns the version. Build generates `plugin/product.json`, `plugin/manifest.json` and `dist/Photoshop-Tool-<version>.ccx`. Do not silently change issued version bytes.
- Runtime is Photoshop UXP, not Node/browser/ExtendScript. Keep `node:*`, fs/child_process and build modules out of `plugin/`.
- Tools register in `plugin/tools/index.js`; the panel and menu consume that registry. Retain the stable plugin ID `com.nasaat.pngrelay`, panel ID `relayPanel`, original commands and legacy `pngrelay.*` preference keys.
- Resolve project-folder Entries before modal work, revalidate targets and await all host changes. The owner requested automatic export beside the PSD: `fullAccess` replaces per-folder pickers. Preserve unrelated layers, selection, document path, source save state and output recovery. History cannot undo external files/clipboard.
- Keep scope and claims precise: mocks/builds do not prove native Photoshop rendering, clipboard alpha, Defender acceptance or flicker resolution.
- Copy is visible by default and copies the entire visible composition, ignoring the source selection/active layer. Keep source layers/selection intact. PNG + Copy and Copy share a temporary merged document pipeline; do not reopen output PNGs merely to copy. Validate staged PNG dimensions/depth/mode/structure/CRCs before clipboard updates and final file replacement. This is not pixel decoding or visual verification; keep diagnostics/docs honest about it.
- Smart Object extraction lives in `tools/png/smart-object.js`: one selected pixel layer + selection uses that layer; all other layer states or no selection use Stamp Visible with `duplicate:true`. Preserve exact feathered selection with an owned alpha channel, use an explicit canvas rectangle for no-selection input, place owned helpers outside groups and retain one final Smart Object. Roll back temporary layers/channels through parent history on failure; never substitute destructive mergeVisible without duplicate.
- No network, native helpers, process launch or background polling. `clipboard: readAndWrite` is required by UXP for the owner's Copy report action; runtime only writes text explicitly and never reads clipboard content. PNG image copying remains native Photoshop. Preserve the report's session bounds and original errors when cleanup also fails.
- Preserve the MIT license and original project provenance: https://github.com/NasaatR/Photoshop_Tool. Product credit remains Made by Nasaat; it does not add license restrictions.
