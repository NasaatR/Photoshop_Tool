# Мои предпочтения для Photoshop-инструментов

- Windows 11 и актуальный Photoshop. Установка — готовым `.ccx` через Creative Cloud, без обязательного UXP Developer Tool, AHK, PowerShell или отдельного EXE-помощника.
- Компактная адаптивная панель: размер можно менять в доке и плавающем окне. Настройки и длинные сообщения не обрезаются; при нехватке места есть прокрутка.
- Аккуратный нейтральный дизайн, скруглённые кнопки, одинаково выровненные иконки, понятные названия и подсказки. Подписи можно скрыть. Единый стиль для настроек, тем, ошибок и отключённых состояний. Небольшая подпись Made by Nasaat.
- Частые действия доступны одной кнопкой. PNG + Copy сохраняет рядом с PSD под тем же именем и копирует картинку; Copy отдельно копирует всю видимую композицию без файла. Без повторного выбора папки. Полное разрешение и сжатие без потерь; без скрытых преобразований исходника.
- Extract + PNG (извлечение в Smart Object с экспортом) работает и без подходящего выбранного слоя: использует недеструктивную сводную копию видимых слоёв. Без области — весь холст. Сохраняет мягкое выделение и исходные редактируемые слои, открывает содержимое, экспортирует PNG и копирует изображение. Служебные слои/каналы убирает.
- Отдельные Smart Object и Camera Raw работают с целыми выбранными слоями; без выбранного слоя делают сводную копию видимых. Camera Raw — как Smart Filter. Чёрная маска, Curves/Hue-Saturation сразу с clipping и Solid Color доступны отдельными кнопками. Экспорт и инструменты слоёв не смешивать; новые команды работают без сохранённого PSD.
- Меньше переключений документов, мигания и лишней работы. Повторные клики блокируются, ошибки не уничтожают исходник, есть отмена/откат и безопасная замена PNG. Настройки сохраняются при обновлении.
- Отчёт об ошибке копируется одной кнопкой и сохраняется в TXT: реальные версии Photoshop/UXP/плагина, точный этап, ID, исходная ошибка и ошибки очистки. Без автоматической отправки данных.
- Расширяемая общая основа для новых инструментов. Стабильные ID, согласованный GitHub-репозиторий/ветка, готовый установщик с понятной версией. Защиту Windows не отключать и не объявлять пакет проверенным Defender без реального теста.
- Проверять отсутствие выбранного слоя/области, группы, текст, смарт-объекты, несколько слоёв, повторные действия и откат. Моки и сборка не заменяют проверку в настоящем Photoshop; непроверенное обозначать прямо.

Технический урок текущего проекта: после make/merge/delete/convert хранить числовые ID и заново получать существующие объекты слоёв. Не обращаться к старому объекту служебного слоя, который Photoshop уже мог удалить. Версию Photoshop читать из `require('uxp').host.version`.
