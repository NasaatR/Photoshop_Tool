# Photoshop Tool

Общая основа UXP-плагина Photoshop от NasaatR. Новые инструменты подключаются к единому реестру: кнопки и команды меню создаются автоматически. Общие сервисы отвечают за запуск, настройки, доступ к папкам, диагностику и восстановление файлов.

[English](README.md)

## Установка

**Предварительная версия 1.8:** [Скачать Photoshop-Tool-v1.8.ccx](https://github.com/NasaatR/Photoshop_Tool/raw/refs/heads/develop/dist/Photoshop-Tool-v1.8.ccx).

1. Закрой Photoshop. Дважды нажми `.ccx` и подтверди установку/обновление в Creative Cloud.
2. Открой Photoshop → **Plugins → Photoshop Tool → Photoshop Tool**.
3. При обновлении подтверди новые разрешения на файлы и буфер. Папка определяется по пути сохранённого PSD; выбирать её перед экспортом больше не нужно.

UXP Developer Tool для установки CCX не нужен. Плагин обновляет прежний **PNG Relay**: ID, команды, настройки экспорта и ключи разрешений папок сохранены. Если загружена копия через UDT, сначала выгрузи её. Удаление — Creative Cloud → Manage Plugins → Uninstall; экспортированные файлы остаются.

Код находится во второй ветке **develop**, `main` не менялась. Файл CCX хранится в репозитории; это не публикация в Adobe Marketplace и не отдельный GitHub Release.

## Версионность

Переход с 0.3.5 на **1.0** согласован владельцем. Внутри CCX версия **1.0.0**. Следующие выпуски: **1.1 … 1.9 → 2.0**, внутри манифеста — **1.1.0 … 1.9.0 → 2.0.0**. Это последовательные номера выпусков. Источник один — `package.json`; короткий номер, метаданные и имя CCX выводятся сборкой. ID плагина, команды и настройки сохранены. Старые установщики не переименовываются.

## Перестановка кнопок

Нажми значок **Arrange buttons** со стрелками в верхней панели. Перетащи кнопку на нужную позицию, либо нажми сначала на неё, затем на место назначения. Стрелки клавиатуры тоже перемещают выбранную кнопку. Порядок меняется внутри секций Export & copy / Area & transform / Layers и сохраняется автоматически; инструменты во время перестановки не запускаются. **Done** или Escape завершают режим. **Reset order** сбрасывает только порядок, сохраняя видимость и остальные настройки.

## Инструменты

- **PNG + Copy:** весь видимый холст → PNG рядом с PSD + копирование изображения.
- **Copy:** весь видимый результат всех слоёв одной картинкой в буфер — без сохранения PNG. Текущее выделение и выбранный слой не ограничивают копирование. Работает и на несохранённом документе.
- **Smart Area:** выделенная область или весь холст → новый смарт-объект → открыть → PNG рядом с родительским PSD + копирование. При отсутствии подходящего пиксельного слоя автоматически создаётся сводная копия видимого результата.
- **PNG only:** сохранить без замены картинки в буфере.

Все инструменты, кроме **PNG only**, видны по умолчанию; сохранённые настройки видимости учитываются. **PNG only** включается в **шестерёнка → Buttons**. Все тринадцать команд доступны и в меню Plugins. Copy копирует изображение для Ctrl+V, а не путь к файлу или отдельные слои; скрытые слои не включаются в композицию.

Кнопки получили заливку, скругления и подписи, иконки — единый размер. Статус отделён от инструментов и показывает результат индикатором. Дополнительные видимые инструменты располагаются в две колонки. При обновлении один раз включаются подписи и Rounded; тема, плотность, экспорт и видимость инструментов сохраняются. Последующие изменения оформления не сбрасываются.

Подписи, размер кнопок, углы и тема настраиваются; Auto следует теме Photoshop. Строка статуса раскрывает полное имя файла или ошибку. Справа от статуса — маленькая иконка документа **Copy report** для текстового отчёта. Большая кнопка **Copy** копирует саму картинку.

Размер плавающей панели меняется перетаскиванием её края/угла, закреплённой — разделителя дока. В манифесте явно разрешён диапазон 176×96–4096×4096; у доков Photoshop могут быть свои ограничения. При уменьшении инструменты прокручиваются внутри панели. Настройки открываются отдельным окном с собственной прокруткой.

В секции **Layers** добавлены отдельные кнопки:

- **Smart Object:** превращает выбранный слой/группу или несколько слоёв в смарт-объект. Если слои не выбраны, сначала делает сводную копию видимых слоёв, сохраняя исходники. Уже готовый смарт-объект повторно не оборачивает.
- **Camera Raw:** тот же выбор исходника → смарт-объект → штатное окно Camera Raw. OK применяет Smart Filter, Cancel откатывает всю команду. Для фильтра нужен RGB/Grayscale, 8/16 бит.
- **Mask:** добавляет чёрную пиксельную маску на один разблокированный слой/группу; при существующей маске инвертирует её целиком. Плотность и растушёвка маски сохраняются, выделение восстанавливается. Специальный Background сначала нужно разблокировать. После создания маска выбрана: можно рисовать белым.
- **Curves** и **Hue / Sat:** нейтральные корректирующие слои прямо над одним выбранным слоем/группой, сразу как clipping mask. Настраиваются через Properties Photoshop. При существующей цепочке clipping действуют штатные правила Photoshop.
- **Solid Color:** штатный выбор цвета → редактируемый слой-заливка без clipping. Отмена ничего не добавляет. При вставке внутрь цепочки clipping заливка переносится над цепочкой, чтобы не отвязывать прежние слои.

Эти семь кнопок работают и в несохранённом документе: папку, экспорт PNG и буфер не используют. Новые Smart Object/Camera Raw работают с целыми слоями, сохраняя мягкое пиксельное выделение; содержимое не открывают. Прежнее извлечение области с экспортом называется **Smart Area** и осталось отдельным инструментом. Для корректирующих слоёв и заливки текущее выделение следует штатному поведению масок Photoshop. Если активна маска/канал, инструменты слоёв сами выбирают композитный канал.

Панель разделена на **Export & copy**, **Area & transform** и **Layers**. Layers без подписей: квадратные кнопки 32×32 px (Roomy — 36×36), с переносом, без растягивания на две широкие колонки. С подписями — три колонки высотой 56/62 px. Наведение и клавиатурный фокус показывают короткое название внутри текущего окна. Подсказку можно прочитать, переведя на неё мышь, или закрыть Escape; она не зависит от штатного HTML title. Скрыть отдельные кнопки можно в шестерёнке; пустая секция исчезает. Скругления, подписи, темы, прокрутка и свободный ресайз сохранены. Новые команды не зависят от некорректного черновика PNG-настроек.

## Smart Area, Fill Current Layer и Quick PSD

- **Smart Area** — новое имя Extract + PNG. На созданном смарт-объекте в родительском документе появляется обычная пиксельная маска с мягким переходом. В 1.5 размытие применяется **один раз к пикселям маски**, а **Feather остаётся 0**: новые мазки кисти и ластика дополнительно не растушёвываются. Содержимое объекта, PNG и буфер остаются без этой внешней маски. **Settings → Actions → Smart Area → Edge blur · %**: по умолчанию 5%, диапазон 0–100 с дробными значениями. Процент считается от короткой стороны области: 1000×600 px при 5% → радиус 30 px. Для совместимости радиус ограничен 0.1–250 px; 0% отключает размытие. Контур сжимается внутрь с сохранением центра; слишком узкая область сохраняет исходный контур с предупреждением. Исходное выделение восстанавливается. Старые маски и рисунок на них обновление не меняет.
- **Fill Current Layer** (короткая подпись **Fill Layer**) — пропорционально увеличивает/уменьшает один выбранный слой до заполнения всего холста и центрирует его. Лишнее остаётся за границами холста. Холст не меняется, смарт-объект не растрируется, выделение восстанавливается. Работает и при активной миниатюре маски. Нужен один непустой разблокированный слой; связанные слои сначала нужно отвязать, чтобы не изменить их вместе. Один шаг Undo.
- **Quick PSD** — сохраняет изображение в PSD рядом с оригиналом, сохраняя слои, профиль и каналы; рабочий документ переключается на новый PSD. PNG/JPEG/TIFF-оригинал не перезаписывается. Если имя занято, добавляется номер. Повторное нажатие сохраняет текущий PSD; существующий PSB сохраняется как PSB. Для документа без локального пути открывается выбор места сохранения. Слишком большой для PSD холст требует PSB. Ошибки штатного сохранения видны в отчёте; неопределённый результат не удаляется, если документ уже привязан к нему.

Процент сохраняется отдельно от прежней настройки в пикселях. Старые значения в пикселях не удаляются и не трактуются как проценты: 0 остаётся 0, прочие переходят на новый стартовый вариант 5%.

Команды, настройки видимости и порядок Smart Area сохранены. Новые кнопки используют прежние подсказки, настройку видимости и перестановку; исправленная прокрутка 1.3 не менялась. Нативная проверка в Photoshop здесь не выполнена: проверь мягкую границу объекта в исходном документе, масштабирование слоя и открытие полученного PSD со всеми слоями.

## Новое в 1.6

- **Expand Selection** — расширить текущее выделение на **8 px** за нажатие. Настройка: **Settings → Actions → Expand Selection → Grow by**; целое число 1–500 px. Повторное нажатие расширяет уже полученное выделение. Один шаг Undo на нажатие; пиксели, слои и маски не меняются. Без выделения появляется сообщение, а не выделение всего холста.
- **Fill Current Layer** и **Expand Selection** — крупные кнопки в **Area & transform**, как сохранение и Smart Area. Остальные шесть кнопок Layers остаются компактными. ID и видимость Fill сохраняются, перестановка работает внутри новой секции.
- На значках сохранения постоянно видны **PNG** / **PSD**, даже при скрытых подписях.
- **Actions** открывает параметры инструментов; **View** — оформление, **Buttons** — видимость/порядок, **Help** — диагностику. Последняя вкладка запоминается. У числовых параметров есть единицы и отдельный **Reset**. Значения сохраняются независимо: незавершённый ввод PNG compression не мешает настроить Expand Selection. **Saved** появляется после успешной записи; при ошибке черновик остаётся в поле, прежнее сохранённое значение не меняется.

Нативную работу Expand Selection и обновлённый вид панели в Photoshop здесь проверить не удалось. Проверь сложное выделение, повторное расширение и Undo, крупные кнопки и настройки при узкой/низкой панели.

## Новое в 1.8

Шестерёнка открывает отдельное окно **Photoshop Tool · Settings**. Стартовый размер — 420×560 px; окно можно менять от 300×260 до 1200×1200. Собственная прокрутка, вкладки View / Buttons / Actions / Help и нижняя строка Close/статуса не сдвигают основные инструменты. Вкладка и введённые значения сохраняются при повторном открытии. Закрытие — Close, крестик или Escape; если видна подсказка, первый Escape закрывает её. Перед запуском инструмента закрой настройки; Arrange buttons возвращает к перестановке в основной панели.

Белая рамка фокуса появляется при работе с клавиатурой, а не остаётся после клика мышью по шестерёнке. Expand Selection получил иконку с четырьмя стрелками наружу. **Camera Raw** и **Mask / Invert** теперь крупные, рядом с Expand/Fill; четыре остальных инструмента Layers компактные. Настройки темы, размеров, видимости и порядка сохранены. Новая иконка Lucide включена с лицензией LICENSE-LUCIDE.txt.

Проверки исходников, имитации интерфейса и CCX выполнены отдельно от нативной проверки: реальное окно, его прокрутка и фокус в Photoshop здесь не проверялись.

## Новое в 1.7

Верхние PNG, Copy, Smart Area и PSD теперь размещаются **в один ряд из четырёх** при достаточной ширине. Основные кнопки без подписей по умолчанию высотой **40 px**, Roomy — 48 px; на узкой панели кнопки переносятся, Layers остаётся компактным.

**Settings → View → Main button height** — слайдер высоты с немедленным предпросмотром и точным вводом в px. Сохранение — при отпускании; Reset возвращает значение текущего пресета Compact/Roomy. Выбор пресета снимает пользовательскую высоту. Точный ввод 36–4096 px доступен и за пределами удобного начального диапазона слайдера 36–96 px; шкала расширяется, а не обрезает значение.

В **Actions** слайдеры добавлены к Grow by, Edge blur и Compression. Поля точного ввода, единицы и действительные диапазоны сохраняются. Двойной щелчок по слайдеру или **Reset** возвращает значение по умолчанию. Само движение слайдеров не меняет документ Photoshop. Настройки, порядок кнопок и прокрутка сохранены; нативный вид/работу слайдеров Photoshop здесь проверить не удалось.

## Качество и ограничения

Windows 11, Photoshop 26.9+. Исходное разрешение, RGB/Grayscale, 8/16 bit, без сжатия с потерями. Другие режимы и HDR не преобразуются автоматически. sRGB применяется только к временной копии по включённой настройке. PSD автоматически не сохраняется и не сводится.

| Состояние при нажатии Smart Area | Источник |
| --- | --- |
| Один пиксельный слой + выделенная область | Содержимое этого слоя, как раньше. |
| Текст, группа, корректирующий слой, смарт-объект, несколько слоёв или ни одного выбранного + выделенная область | Сводная копия всех видимых слоёв, затем извлечение области. |
| Нет выделенной области | Сводная копия всего холста независимо от выбранного слоя. |

Сводная копия создаётся штатным Stamp Visible — эквивалентом Shift+Ctrl+Alt+E. Исходные слои не объединяются и не удаляются; скрытые не включаются. Для мягкого/сложного выделения используется временный альфа-канал, чтобы сохранить его точную форму. После извлечения на смарт-объекте в родительском документе создаётся отдельная мягкая маска. Служебные слои и канал удаляются после извлечения; в PSD остаётся один новый смарт-объект и исходные слои. Без области используется прямоугольник всего холста, затем восстанавливается отсутствие выделения. Quick Mask и отдельный канал/маска вместо RGB/Grayscale пока требуют перехода на составной канал.

Подготовка и создание объекта объединены в один шаг истории родительского документа. При ошибке до завершения создания выполняется откат. Содержимое нового объекта остаётся открытым; если дальнейший экспорт не удался, используй PNG + Copy внутри него для повтора. Связь с родительской папкой хранится в текущем сеансе плагина.

Буфер — штатный буфер изображения Photoshop. Прозрачность, разрядность и поддержка вставки зависят от принимающего приложения. Если предложена **Enable external paste**, она явно включает Export Clipboard в Photoshop. Настройки защиты Windows не меняются.

Для сохранения и копирования теперь используется одна временная сводная копия документа. Сохранённый PNG не открывается повторно в Photoshop: до копирования/замены файла проверяются его размеры, разрядность, цветовой режим, структура и контрольные суммы всех блоков. Это чтение сжатого файла в память и проверка целостности, не декодирование пикселей и не визуальная проверка ICC. Исходные слои и выделение сохраняются.

Лишнее открытие/закрытие PNG убрано, поэтому переключений документов стало меньше. Временный документ и штатные операции Photoshop ещё могут вызывать перерисовку; полное исчезновение мигания без проверки в Photoshop не подтверждено.

Перед заменой PNG сохраняется временная резервная копия. При ошибке предпринимается восстановление; это не атомарная файловая транзакция. Не запускай два экспортёра на один путь одновременно. После сбоя могут остаться `.photoshoptool-export-*` / `.photoshoptool-backup-*`; сначала проверь их содержимое. PSD никогда не удаляется.

Файл, буфер и изменения документа — разные эффекты. При частичном выполнении статус сообщает, что успело сохраниться/скопироваться. Undo в PSD не восстанавливает файлы или старый буфер. После ошибки экспорта выделения повторяй первую кнопку внутри уже созданного объекта, а не создавай новый объект повторным Smart Area.

## Основа для новых инструментов

[Как добавить инструмент](docs/adding-tools.md): отдельный модуль, запись в реестре, иконка и проверки. Панель и меню не нужно дублировать вручную. Общие настройки, обработка ошибок, блокировка повторного запуска и файловое восстановление переиспользуются.

Для разработки: Node.js 22+, без внешних npm-зависимостей. `npm test`, `npm run build`, `npm run check`. Пользователю для установки это не требуется. Сборка воспроизводима; версия задаётся в `package.json`.

## Проверка

Локально выполняются тесты с имитацией Photoshop, файловой системы и интерфейса, проверки синтаксиса, соответствия реестра меню и содержимого CCX. GitHub-проверка повторяет их и сравнивает установщик с результатом сборки. Она ничего не публикует и не развёртывает.

Работу 0.1.1 пользователь подтвердил ранее. Версия 1.7 здесь ещё не запускалась в настоящем Photoshop: Stamp Visible, сохранение мягкого выделения через альфа-канал, отображение/ресайз, вставка в другие приложения, ICC и результат Defender не подтверждены. Доступен контроль структуры/клавиатуры/настроек с имитацией DOM, без визуальной проверки этой версии в Photoshop. Причина белого мигания пока не установлена.

## Отчёт об ошибках

Нажми иконку копирования рядом со статусом (**Copy report**), затем Ctrl+V в чате. Та же кнопка есть в **шестерёнка → Help & report**, рядом с **Save report .txt** для сохранения файла. Копирование отчёта заменяет картинку в буфере текстом; сохранение `.txt` буфер не меняет.

Отчёт содержит версии, размеры панели, настройки, параметры исходного документа, этапы/время операций, выполненные эффекты, ошибки с кодами/стеком/причинами и отдельные ошибки очистки. Сохраняются последние 8 операций и 100 событий текущего сеанса плагина, включая ошибки проверки настроек и экспорта отчёта. Последующий успешный запуск не стирает прошлые ошибки. После перезапуска журнал начинается заново. Это журнал плагина, а не всех ошибок Photoshop. Локальные абсолютные пути скрываются, но имена PNG и текст ошибок могут остаться — проверь перед пересылкой. Автоматической отправки данных нет.

Для экспорта без выбора папки используется `localFileSystem: fullAccess`. Для записи текста отчёта UXP требует `clipboard: readAndWrite`; код буфер не читает. Старые настройки и ключи доступа сохранены.

В 0.3.4 исправлен сценарий обращения к устаревшему объекту служебного слоя после Stamp Visible. Слои заново находятся по актуальным ID; уже удалённый Photoshop служебный слой повторно не удаляется. Владелец сообщил о работающих инструментах 0.3.5. В 1.0 дополнительно убрана лишняя команда Move для корректирующих слоёв и заливки, уже стоящих над нужным слоем. Подсказки, быстрые переходы, фокус, отмена таймеров и короткая/нативная версии проверяются с имитацией интерфейса. Реальный вид новых подсказок в Photoshop здесь не проверялся.

В 1.1 исправлены пути, вызывавшие мигание подсказок: они размещаются в свободном месте над/под кнопкой, не накрывают собственную кнопку и не закрываются от служебного blur/изменения раскладки. При нехватке места текст прокручивается. Отчёт содержит счётчики подсказок и причину последнего закрытия.

Все семь кнопок Layers определяют слой-владельца по native ID даже при активной миниатюре маски, затем выбирают изображение слоя без чтения свойств DOM-канала маски. Кнопка Mask инвертирует существующую маску целиком. Нативные изменения маски/изображения и жесты новой перестановки в Photoshop здесь ещё не проверялись.

В 1.2 кнопка **Black Mask / Invert** при повторном нажатии инвертирует существующую маску; ещё одно нажатие возвращает её обратно. При отсутствии маски создаёт чёрную. Текущее пиксельное выделение не ограничивает инверсию маски; изображение слоя не инвертируется.

Подсказки сокращены до названий. Настройки разбиты на **View / Tools / Export / Help**, длинная инструкция открывается отдельно, отчёты доступны сразу во вкладке Help. Переключение вкладок не сбрасывает введённые значения. В ограниченной по высоте области панели включена автоматическая вертикальная прокрутка; доступны колесо мыши, Page Up/Page Down, а при фокусе области — Home/End. Размер окна Photoshop/перекрытие другим окном плагин автоматически не определяет.

Эти изменения проверены исходниками/имитацией/сборкой; нативная инверсия маски и новая раскладка в Photoshop здесь ещё не проверялись.

В 1.3 восстановлена раскладка после сбоя 1.2, при котором оставалась видна только подпись снизу. Основная область и подпись снова находятся в обычном потоке. Высота прокрутки задаётся в пикселях по размеру контейнера; обновляется при показе и ресайзе, без фонового опроса. Нулевой размер во время скрытия/загрузки не схлопывает содержимое. Порядок, видимость, настройки, короткие подсказки и инверсия маски сохранены. В диагностике есть `interface.scroll.layout` с измеренными размерами. Нативная проверка восстановленного вида Photoshop здесь ещё не выполнялась.
